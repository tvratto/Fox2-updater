Manifest Format Reference

How to create a manifest JSON for each release ▾

Create one manifest-vX.Y.Z.json per release in your /firmware/ folder:

{ "name": "FOX2 v1.0.0", "version": "1.0.0", "home_assistant_domain": "esphome", "builds": [ { "chipFamily": "ESP32", "parts": [ { "path": "fox2-v1.0.0.bin", "offset": 0 } ] } ] }

Use offset 0 for a merged binary (Arduino IDE: Sketch → Export Compiled Binary). The path is relative to the manifest file.
